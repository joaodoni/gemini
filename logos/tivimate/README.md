# Logos para Tivimate

Esta pasta guarda os logotipos dos canais para uso no Tivimate (IPTV).

- Coloque aqui os arquivos de imagem (PNG, JPG, SVG).
- Recomendo nomear os arquivos com o nome do canal em minúsculas e sem espaços, por exemplo: `globo.png`, `tvcultura.png`.
- Se você prefere usar IDs específicos da sua lista M3U, me envie a M3U e eu posso renomear os arquivos para combinar.

Como adicionar logos:
- Pelo GitHub: clique em "Add file" → "Upload files" e envie as imagens para esta pasta.
- Pela sua máquina: clone o repositório, copie os arquivos para `logos/tivimate/` e faça commit/push.

Se quiser, eu posso:
- Redimensionar, converter ou otimizar os logos automaticamente;
- Renomear os arquivos para casar com sua lista M3U;
- Fazer upload das imagens a partir de URLs que você fornecer.

Diga o que prefere que eu faça em seguida.
